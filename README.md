## Quick Start (Windows / Linux / macOS)

```sh
# Clone & enter repository (all platforms)
git clone https://github.com/awesome-os/benchy.git && cd benchy
```

## Quick Install & Run (Windows / Linux / macOS)

```sh
# Install / hydrate from v11 CAS via holo-pm
holo-pm install repository://github.com/awesome-os/benchy@main

# Or project & run directly via holo-project (0-byte hardlink)
holo-project "project://cpp/benchy?from=repository://github.com/awesome-os/benchy@main"
```
